## Release workflow

The `validate` job accepted the verified annotated tag, a clean tree, matching versions in `Cargo.toml` and `plugin.json`, and the immutable shared pin. Each of the five build jobs ran on its native runner. Each one:

- ran formatting, clippy, and the stable and Rust 1.85 test suites;
- built the release binary with the source and shared revisions embedded;
- checked the binary's `build-info` target and source revision;
- packaged the binary with its release manifest and the license;
- generated SLSA v1 provenance and signed the archive with Cosign.

The Windows job also passed `scripts/windows-hook-smoke.ps1`. `publish` created the release with signed `SHA256SUMS`, and `marketplace-package` rebuilt the package from the published assets, verifying every signature, checksum, provenance record, and manifest.

## Marketplace publication

`scripts/publish-marketplace-branch.sh 0.5.0 marketplace-pilot` ran from a clean checkout of `main` at the tagged commit. Before committing, it re-verified the signed checksums and all five archives' signatures and provenance. The branch contains exactly:

- `.github/plugin/marketplace.json` (`upld-internal`, `burnrate-copilot` 0.5.0, source `./plugin/burnrate-copilot`);
- the plugin's tracked files and `bin/<target>/burnrate-copilot[.exe]` for all five targets;
- `LICENSE` and `release-evidence.json`.

- `copilot plugin marketplace add 'upld-internal/burnrate-copilot#marketplace-pilot'` added the marketplace.
- `copilot plugin install burnrate-copilot@upld-internal` installed v0.5.0 with its `setup-langfuse` skill.
